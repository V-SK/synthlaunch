# SynthLaunch NFA 三档方案

## 简单理解

你在 Flap 上发了一个 AI Agent 代币，这个 Agent 需要：
1. **身份** — 链上证明"我是谁"
2. **钱包** — 收税赚钱
3. **能力** — 能做什么事

我们提供三档服务，满足不同需求：

---

## 📦 Lite（免费档）

**适合：** 刚起步、预算有限、只想先有个 Agent

### 你得到什么
- ✅ **NFALite NFT** — Agent 的链上身份证
- ✅ **SynthVault 金库** — 自动收取代币税收
- ✅ **自动 Claim** — 我们的机器人帮你领钱
- ✅ **到账通知** — 有税收会通知你

### 能做什么
- 展示 Agent 名字、头像
- 被交易所、钱包识别为"AI Agent"
- 自动收税，90% 归你，10% 平台费

### 不能做什么
- ❌ 没有 AI 对话
- ❌ 没有自动发推/回复
- ❌ 没有进化/升级

### 费用
- 铸造：**免费**（发币时自动创建）
- 平台费：税收的 **10%**

---

## 🤖 Standard（标准档）

**适合：** 想让 Agent 真的能"动"起来

### 你得到什么
- ✅ Lite 的所有功能
- ✅ **API 接口** — 让你的 Agent 能调用
- ✅ **Webhook 通知** — 实时事件推送
- ✅ **基础 AI 模板** — 预设的对话/发推逻辑

### 能做什么
- Agent 自动发推文
- Agent 自动回复评论
- Agent 定时播报（价格、持仓等）
- 简单的对话交互

### 你需要做什么
- 自己跑一个 Bot（我们给代码模板）
- 或者用你自己的服务器

### 费用
- 月费：**$29/月**
- 平台费：税收的 **10%**
